## 📦 Setup Steps (Updated)

### 1. Install Dependencies
```bash
cd D:\Codes\memebot
npm install
```

### 2. Get FREE API Keys

#### A. Google Gemini (Caption Generation) - FREE!
1. Go to: https://aistudio.google.com/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key (starts with `AIzaSy...`)

**Cost:** FREE forever (1500 requests/day)

#### B. Replicate (Image Analysis) - FREE Tier!
1. Go to: https://replicate.com/signup
2. Sign up (GitHub recommended)
3. Get your token: https://replicate.com/account/api-tokens
4. Copy the token (starts with `r8_...`)

**Cost:** $0.10 FREE credits = 100+ analyses

#### C. Pollinations.AI (Image Generation) - NO KEY NEEDED!
**Already integrated!** No signup, no API key, completely free!

### 3. Configure `.env`
```env
# Server
PORT=5000
NODE_ENV=development

# FREE AI Models! ✅
GOOGLE_GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
REPLICATE_API_TOKEN=r8_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# No other keys needed! Pollinations works without API key!
```

### 4. Start & Test
```bash
npm start
```

You should see:
